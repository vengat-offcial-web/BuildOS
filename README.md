# 🏗️ BuildOS — Enterprise Construction Operations Platform

Welcome to **BuildOS**, a modern web application for construction site management, real-time workforce tracking, project logistics, and site operations.

## 📁 Repository Structure

- **[`BuildOS/`](./BuildOS)** — Main React 19 + Vite web application codebase.

---

## 🚀 Quick Start

To run the application locally:

```bash
cd BuildOS
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.
